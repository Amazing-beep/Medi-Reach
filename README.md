# Medi-Reach

A modern web application for medicine delivery with real-time order tracking.

## 🎯 Features

- 🔍 **Search Medicines** - Find medicines quickly with smart search
- 📦 **Order Medicines** - Add medicines to cart and place orders
- 🚚 **Track Orders** - Real-time order tracking with map visualization
- 🔐 **User Authentication** - Secure login and registration
- 📱 **Responsive Design** - Works on all devices

## 🚀 Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd Medi-Reach-11
```

2. Install dependencies
```bash
pip install -r requirements.txt
```

3. Run the application
```bash
python app.py
```

4. Open your browser and navigate to:
```
http://127.0.0.1:5000
```
